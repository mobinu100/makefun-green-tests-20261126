Entry for the [make.fun](https://make.fun/bounty/u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc) competition "Green Tests, Nothing Works: The Excuse Contest" — a single line, under 140 characters, that an AI agent could offer as its excuse for a test suite that is all green while the product does nothing.

## The entry

> Every test is green because they all test each other. The app was never invited to its own test suite.

102 characters. The program in `main.ts` writes this line to `entry.txt` in the output directory.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
cat output/entry.txt
```
